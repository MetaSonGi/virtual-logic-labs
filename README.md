# Virtual Logic Labs (Web)

2018년 Rutgers 대학교 ECE 학과 프로젝트 **Virtual Logic Labs**를 Unity 6로 옮긴 뒤, **3D 회로 실험실**을 중심으로 **논리 회로 · 공압 · 유압 실험 11개**를 새로 만든 WebGL 버전입니다. 로그인 없이 실험을 골라 바로 시작합니다.

🌐 **바로 실행:** https://metasongi.github.io/virtual-logic-labs/

## 실험 목록
| # | 분야 | 실험 | 목표 |
|---|---|---|---|
| 1 | 논리 회로 | 논리 회로 자유 실험 | 반가산기 예제로 시작 |
| 2 | 논리 회로 | NOT 게이트 | Y = NOT A |
| 3 | 논리 회로 | AND 게이트 | Y = A · B |
| 4 | 논리 회로 | XOR 직접 만들기 | AND·OR·NOT만으로 XOR |
| 5 | 논리 회로 | 반가산기 | S = A xor B, C = A · B |
| 6 | 논리 회로 | 다수결 회로 | 3개 중 2개 이상 ON |
| 7 | 공압 | 복동 실린더 전진·후진 | 스위치 → 5/2 밸브 → 실린더 |
| 8 | 공압 | 양수 안전 회로 | 두 버튼 AND → 3/2 밸브 → 단동 실린더 |
| 9 | 공압 | 자동 왕복 운동 | 센서 S0·S1 + SR 래치 자기유지 |
| 10 | 유압 | 유압 실린더 제어 | 펌프·밸브·실린더 + 탱크 복귀(R→T) |
| 11 | 공유압 | 공유압 자유 실험 | 공압 예제로 시작 |

미션은 **채점하기**로 자동 채점합니다. 논리 회로는 진리표 전체를, 공유압은 스위치 조합마다 시뮬레이션을 돌려 실린더가 맞는 끝까지 가는지(자동 왕복은 20초 동안 2회 이상 왕복 후 정지)를 확인합니다. 완료한 실험은 ✓로 표시되고 브라우저에 저장됩니다.

## 부품
| 분류 | 부품 |
|---|---|
| 전기·논리 | 스위치, LED, AND · OR · NOT · NAND · NOR · XOR, **SR 래치**(자기유지) |
| 공압 | **압축기**(P), **5/2 밸브**(P·A·B·R, 솔레노이드 코일), **3/2 밸브**(P·A·R), **복동 실린더**(A·B), **단동 실린더**(A, 스프링 복귀) |
| 유압 | **유압 펌프**(P 공급 · T 탱크) — 밸브 R을 T로 돌려야 실린더가 움직임 |
| 센서 | 실린더마다 **S0**(후진 끝) · **S1**(전진 끝) 전기 출력 |

## 조작법
- **전원**: 보드 뒤 5V 전원 공급기의 **POWER** 버튼(또는 스페이스바). 켜야 신호가 흐르고 압축기·펌프가 돌아갑니다.
- **전선**: 핀(●)을 끌어 다른 부품의 핀에 놓기(또는 핀을 차례로 클릭) — 전선은 3D 곡선, 켜지면 초록빛과 흐르는 빛 알갱이
- **호스**: 포트(파란 고리 ●)끼리 끌어서 연결 — 압력이 걸리면 공압은 파랑, 유압은 주황으로 빛남
- **스위치**: 클릭으로 ON/OFF · **삭제**: 선택 후 🗑 삭제, 전선·호스는 더블클릭
- **카메라**: 빈 곳 드래그 회전, 오른쪽 드래그 이동, 휠·핀치 확대, <kbd>R</kbd> 처음 위치

## 폴더 구성
| 경로 | 설명 |
|---|---|
| `docs/` | WebGL 빌드 결과물 (GitHub Pages가 이 폴더를 서비스) |
| `Assets/Scripts/Lab3D/LogicSim.cs` | 회로 데이터 · 논리 시뮬레이션 · 공유압(압력/배기 경로, 밸브, 실린더, 센서, 래치) |
| `Assets/Scripts/Lab3D/Experiments.cs` | 실험 11개 정의 · 자동 채점 · 진행 저장 |
| `Assets/Scripts/Lab3D/Lab3D.cs` | 3D 장면 · 부품 모델 · 전선/호스 연결 · 미션 패널 |
| `Assets/Scripts/Lab3D/StartMenu.cs` | 실험 목록 시작 화면 |
| `Assets/Scripts/Lab3D/Lab3DArt.cs`, `UIKit.cs` | 재질·메시·글자, UI 도우미 |
| `Assets/Editor/Lab3DSetup.cs`, `WebGLBuilder.cs` | 장면 생성과 메뉴 **Build → WebGL (docs)** |
| `Assets/WebGLTemplates/Neon/` | 전체 화면 네온 로딩 페이지 |
| `Assets/Scenes/` | 원작 2018 장면 (프로젝트에만 보관, 웹 빌드에는 미포함) |

## 다시 빌드하기
1. Unity Hub에서 이 폴더를 Unity **6000.3.21f1** 로 엽니다.
2. 메뉴 **Build → WebGL (docs)** 를 누르면 장면 준비 후 `docs/` 가 새로 만들어집니다.
3. 커밋·푸시하면 GitHub Pages에 반영됩니다.

## 참고
- 원작의 영문 학생 실습·관리자 화면과 온라인 DB 로그인은 웹 빌드에서 뺐습니다 (원본 장면은 `Assets/Scenes/` 에 그대로 있음).
